# Referências de UX

Open WebUI é apenas referência de experiência. Não foi instalado, integrado nem teve código, marca ou assets copiados.

| Padrão | Uso na Noite | Motivo |
|---|---|---|
| Streaming de respostas | Inserção progressiva no chat | Mostrar resposta assim que chega do núcleo. |
| Parar geração | Ação de cancelamento ligada ao worker | Manter controle durante respostas longas. |
| Seletor de modelo | Modelo local selecionável na conversa | Expor a configuração sem codificar roteamento na UI. |
| Lista de conversas | Sessões persistidas na navegação | Retomar tarefas sem misturar históricos. |
| Markdown | Renderização da resposta após streaming | Preservar formatação legível no chat. |
| Progresso observável | Estado de geração no chat; bloco de pensamento somente quando enviado pelo modelo | Acompanhar a resposta sem inventar nem expor raciocínio privado. |

As imagens da Noite continuam definindo a identidade visual; esses padrões não autorizam reproduzir o visual do Open WebUI.
