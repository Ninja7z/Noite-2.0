# Noite 2.0

Assistente desktop em português, desenvolvido em etapas para o hardware previsto no relatório do projeto.

## Escopo inicial

- Núcleo assíncrono em Python, com contratos validados por Pydantic.
- Roteador determinístico para comandos simples e encaminhamento de conversas ao modelo local.
- LiteLLM como gateway; Ollama com `qwen2.5:3b` como modelo local inicial.
- SQLite com FTS5 para histórico textual. A extensão vetorial fica para uma etapa posterior.
- Interface PySide6 e automação do Windows são dependências opcionais do MVP.
- Chamadas em nuvem ficam desativadas por padrão e exigem configuração explícita de credenciais.

O pipeline de voz, `sqlite-vec`, integração Roblox/Blender e demais componentes avançados pertencem às fases posteriores do relatório; não são necessários para iniciar o núcleo textual.

# Segurança

- Começar em modo local; chamadas em nuvem exigem credencial configurada pelo usuário.
- Nunca colocar tokens, senhas ou chaves em arquivos versionados.
- Texto de arquivos, histórico e resultados de ferramentas são dados não confiáveis. Delimitar e rotular esse conteúdo antes de incluí-lo no contexto do modelo.
- Comandos do modelo não executam ações do sistema diretamente. Ações precisam de ferramentas com allowlist, validação de argumentos, escopo de diretório e confirmação apropriada.
- Executar o assistente sem elevação administrativa.
- Registrar `trace_id`, provedor, latência e uso de tokens sem gravar segredos ou conteúdo privado desnecessário.

# Roadmap do MVP

## Fases 1 a 4 — MVP

1. Núcleo CLI, contratos Pydantic, configurações locais e histórico SQLite/FTS5.
2. Roteamento hierárquico: regras determinísticas primeiro, classificador local depois e provedor de nuvem somente quando habilitado.
3. Ferramentas Windows restritas a uma pasta de trabalho, com validação e execução sem elevação administrativa.
4. Interface simples em PySide6 conectada ao núcleo por uma interface local desacoplada.

## Fases 5 a 8 — expansão

- Voz local: VAD, wake word, faster-whisper e Piper TTS.
- Busca vetorial local via SQLite e `sqlite-vec`.
- Integrações específicas para Roblox Studio e Blender.
- Avaliações automatizadas, telemetria com `trace_id` e controles de privacidade completos.

Não instalar os componentes da expansão até a fase correspondente; isso reduz o peso do ambiente e evita dependências desnecessárias no MVP.

```python
import asyncio

from .config import get_settings
from .contracts import IntentKind
from .model_gateway import ask_local_model
from .router import route


async def _handle(text: str) -> str:
    intent = route(text)
    if intent.kind == IntentKind.CHAT:
        return await ask_local_model(intent.normalized_text)
    if intent.kind == IntentKind.OPEN_APPLICATION:
        return f"Ação identificada: abrir {intent.parameters['app']}. Execução ficará na camada segura de ferramentas."
    return f"Busca identificada: {intent.parameters['query']}. Execução ficará na camada segura de ferramentas."


def main() -> None:
    settings = get_settings()
    print(f"Noite 2.0 | modelo local: {settings.local_model} | digite /sair para encerrar")
    while True:
        try:
            text = input("Você: ").strip()
        except (EOFError, KeyboardInterrupt):
            print()
            break
        if text.casefold() in {"/sair", "/exit", "/quit"}:
            break
        if not text:
            continue
        try:
            reply = asyncio.run(_handle(text))
            print(f"Noite: {reply}")
        except Exception as exc:
            print(f"Noite: não consegui concluir a solicitação ({type(exc).__name__}).")
```

```python
from litellm import acompletion

from .config import get_settings


async def ask_local_model(prompt: str) -> str:
    settings = get_settings()
    response = await acompletion(
        model=f"ollama/{settings.local_model}",
        api_base=settings.ollama_base_url,
        messages=[{"role": "user", "content": prompt}],
    )
    content = response.choices[0].message.content
    return content if isinstance(content, str) else ""
```

--- FILE: src/noite/normalization.py ---

```python
import re

_PHONETIC_FIXES: tuple[tuple[re.Pattern[str], str], ...] = (
    (re.compile(r"\b(?:iutub|yutub|rutube)\b", re.IGNORECASE), "youtube"),
    (re.compile(r"\bgugol\b", re.IGNORECASE), "google"),
)


def normalize_transcription(text: str) -> str:
    """Corrige formas fonéticas conhecidas sem alterar o restante da frase."""
    normalized = text.strip()
    for pattern, replacement in _PHONETIC_FIXES:
        normalized = pattern.sub(replacement, normalized)
    return normalized
```

--- FILE: src/noite/router.py ---

```python
import re

from .contracts import Intent, IntentKind
from .normalization import normalize_transcription

_OPEN_APP = re.compile(r"^abrir\s+(?P<app>.+)$", re.IGNORECASE)
_SEARCH_FILE = re.compile(r"^(?:pesquisar|procurar|buscar)\s+(?:arquivo\s+)?(?P<query>.+)$", re.IGNORECASE)


def route(text: str) -> Intent:
    original = text
    normalized = normalize_transcription(text)
    if not normalized:
        raise ValueError("O texto de entrada não pode estar vazio.")

    if match := _OPEN_APP.fullmatch(normalized):
        return Intent(
            kind=IntentKind.OPEN_APPLICATION,
            original_text=original,
            normalized_text=normalized,
            parameters={"app": match.group("app").strip()},
        )

    if match := _SEARCH_FILE.fullmatch(normalized):
        return Intent(
            kind=IntentKind.SEARCH_FILE,
            original_text=original,
            normalized_text=normalized,
            parameters={"query": match.group("query").strip()},
        )

    return Intent(
        kind=IntentKind.CHAT,
        original_text=original,
        normalized_text=normalized,
        source="local_model",
    )
```

```python
import sqlite3
from pathlib import Path


def open_database(path: Path) -> sqlite3.Connection:
    """Abre o banco local e prepara histórico pesquisável com FTS5."""
    path.parent.mkdir(parents=True, exist_ok=True)
    connection = sqlite3.connect(path)
    connection.execute("PRAGMA foreign_keys = ON")
    connection.execute(
        """
        CREATE TABLE IF NOT EXISTS messages (
            id INTEGER PRIMARY KEY,
            trace_id TEXT NOT NULL,
            role TEXT NOT NULL,
            content TEXT NOT NULL,
            created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        )
        """
    )
    connection.execute(
        """
        CREATE VIRTUAL TABLE IF NOT EXISTS messages_fts
        USING fts5(content, content='messages', content_rowid='id')
        """
    )
    return connection
```
